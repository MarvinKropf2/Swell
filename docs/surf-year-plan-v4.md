# SWELL Surf Year v4 · 12-month surf + strength plan

Approved program implementation for four weekly sessions of approximately 75 minutes. All exact sets, repetitions, movement variations and instructions live in `surf-year-plan-v4.js`.

## Weekly schedule

- Tuesday: Upper A, pop-up, alternating pull/push, chest flies, lateral delts and triceps, short treadmill run.
- Wednesday: only dedicated leg-strength session with squat/deadlift pattern, hamstrings, calves and core.
- Friday: Upper B, alternating pull/push, cable flies, rear delts, arms, shoulder prehab, treadmill intervals.
- Saturday: Surf power, rotational core, paddle pulls, push-ups and longer treadmill run.

Each month retains its original phase, with a week-four deload and lighter testing / bridge weeks as previously configured.
The running targets are conditional, not requirements to run through pain or exceed a manageable effort.

## History safety

Saved workout logs are not edited. Existing users receive a revised program template. If a non-stretching workout was already saved on the update date, the new plan becomes effective the following calendar day. Previously generated exercises that were intentionally removed do not get appended again, but custom additions and saved weights on unchanged exercise IDs are retained.
